# SnapKey Vision AI Brand Assets

Place final brand files here before building the client installer:

```text
assets/brand/logo.png
assets/brand/app.ico
assets/brand/installer-wizard.bmp
assets/brand/installer-banner.bmp
```

Recommended sizes:

```text
logo.png                 transparent PNG, 512x512 or wider
app.ico                  Windows icon containing 16, 32, 48, 128, 256 px
installer-wizard.bmp     Inno Setup large wizard image, usually 164x314 BMP
installer-banner.bmp     Inno Setup top banner image, usually 493x58 BMP
```

The installer and PyInstaller build are configured to use these files directly.
